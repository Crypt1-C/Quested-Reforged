# [Quested: Reforged](https://www.curseforge.com/minecraft/mc-mods/quested-reforged)

**Quested: Reforged** is a modern port of the classic [**Quest Plaques**](https://www.curseforge.com/minecraft/mc-mods/quest-plaques) mod to 1.20.1+! Turn boring quest popups into stylish, glowing plaques that integrate seamlessly with **Advancement Plaques**

- **Glowing quest notifications** for supported quest mods  
- **Customizable**: choose which quest levels show plaques, whitelist quests, skip single-task steps
- **Compatible**: works with **FTB Quests**
- **Client & Server**: must be installed on both  
- **Free to use** in modpacks
